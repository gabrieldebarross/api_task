🚀 API REST — Roadmap de Desenvolvimento
Projeto desenvolvido para estudar e praticar Node.js, APIs REST, autenticação, autorização, banco de dados, segurança, testes, performance, Docker, Redis, WebSockets e deploy.

A proposta não é apenas construir uma API funcional, mas entender o motivo de cada decisão e como cada parte funciona, evoluindo o projeto gradualmente de um CRUD simples para uma aplicação próxima de um ambiente de produção.

🎯 Objetivo
Construir uma API REST completa, evoluindo progressivamente através de diferentes níveis de complexidade.

Durante o desenvolvimento serão praticados:

- **Node.js**
- **APIs REST**
- **HTTP**
- **CRUD**
- **Autenticação**
- **Autorização**
- **JWT**
- **Banco de dados SQL**
- **Relacionamentos**
- **Validação de dados**
- **Segurança**
- **Performance**
- **Testes automatizados**
- **Swagger / OpenAPI**
- **Logs e observabilidade**
- **Docker**
- **Redis**
- **Filas e processamento assíncrono**
- **WebSockets**
- **CI/CD**
- **Deploy**

Regra principal: implementar cada funcionalidade entendendo seu funcionamento e suas decisões, evitando simplesmente copiar implementações prontas.
